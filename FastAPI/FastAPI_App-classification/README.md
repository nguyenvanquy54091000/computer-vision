📸 Image Classification API với FastAPI
Dự án này là một ứng dụng Web API mạnh mẽ và tinh gọn, được xây dựng bằng FastAPI để thực hiện nhiệm vụ phân loại hình ảnh sử dụng các mô hình Deep Learning.

📌 Tính năng chính
Dự đoán nhanh: Sử dụng FastAPI giúp tối ưu hóa tốc độ phản hồi của API.

Dễ dàng tích hợp: API chuẩn RESTful, dễ dàng kết nối với Mobile app hoặc Frontend.

Tài liệu tự động: Tích hợp sẵn Swagger UI để kiểm tra API trực tiếp.

Xử lý hình ảnh: Hỗ trợ nhận file ảnh từ người dùng và trả về nhãn phân loại cùng độ tự tin.

🛠 Công nghệ sử dụng
Ngôn ngữ: Python

Web Framework: FastAPI

Server: Uvicorn

Thư viện AI/CV: TensorFlow/PyTorch, OpenCV, Pillow

Data Validation: Pydantic
